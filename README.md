# EcoMovilidad (app)

App instalable (PWA) de EcoMovilidad. Para publicarla en GitHub Pages:

1. Crea un repositorio público, por ejemplo `ecomovilidad-app`.
2. Sube todos estos archivos a la raíz del repositorio.
3. En Settings → Pages, elige la rama `main` y la carpeta `/ (root)`, y guarda.
4. Abre `https://TU_USUARIO.github.io/ecomovilidad-app/` en Safari y toca Compartir → Agregar a pantalla de inicio.
